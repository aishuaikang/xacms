# 打击设备协议说明

## 协议格式

打击设备使用自定义的二进制协议，格式如下：

```
+--------+--------+--------+--------+--------+--------+--------+--------+
| Header |   ID   |   ID   | Length |  Cmd   |  Data  |  ...   |  Tail  |
| (1字节)|(1字节) |(1字节) |(1字节) |(1字节) |(N字节) |  ...   |(1字节) |
+--------+--------+--------+--------+--------+--------+--------+--------+
  0xAA     高字节   低字节   总长度   命令类型  数据内容   ...     0x55
```

### 字段说明

| 字段   | 长度   | 说明                                |
| ------ | ------ | ----------------------------------- |
| Header | 1 字节 | 协议头，固定为 `0xAA`               |
| ID     | 2 字节 | 设备 ID，大端序                     |
| Length | 1 字节 | 整个数据包的总长度（包含所有字段）  |
| Cmd    | 1 字节 | 命令类型                            |
| Data   | N 字节 | 数据内容（可选，长度为 Length - 6） |
| Tail   | 1 字节 | 协议尾，固定为 `0x55`               |

### 命令类型

| 命令值 | 命令名称        | 说明              |
| ------ | --------------- | ----------------- |
| 0x04   | CmdSetPower     | 设置 N 路开关功率 |
| 0x05   | CmdQueryModules | 查询 N 路模块信息 |
| 0x10   | CmdDownloadAddr | 下载地址列表      |
| 0x11   | CmdQueryAddr    | 查询地址列表      |

## 使用示例

### 1. 发送命令到设备

```go
// 方法1: 使用协议包构造函数
packet := protocol.BuildStrikePacket(
    1,                    // 设备ID
    protocol.CmdSetPower, // 命令类型
    []byte{0x01, 0x64},  // 数据内容
)
err := strikeDevice.SendToDevice("192.168.1.100:8080", packet)

// 方法2: 使用便捷方法
err := strikeDevice.SendPacketToDevice(
    "192.168.1.100:8080", // 设备地址
    1,                    // 设备ID
    protocol.CmdSetPower, // 命令类型
    []byte{0x01, 0x64},  // 数据内容
)
```

### 2. 广播命令到所有设备

```go
strikeDevice.BroadcastPacketToAllDevices(
    0,                         // 设备ID（0表示广播）
    protocol.CmdQueryModules,  // 命令类型
    nil,                       // 无数据
)
```

## 协议示例

### 示例 1: 设置 1 号通道功率为 100%

发送数据包:

```
AA 00 01 08 04 01 64 55
```

字段解析:

-   `AA`: 协议头
-   `00 01`: 设备 ID = 1（大端序）
-   `08`: 总长度 = 8 字节
-   `04`: 命令 = 设置功率
-   `01`: 通道号 = 1
-   `64`: 功率 = 100 (0x64 = 100)
-   `55`: 协议尾

### 示例 2: 查询模块信息

发送数据包:

```
AA 00 01 06 05 55
```

字段解析:

-   `AA`: 协议头
-   `00 01`: 设备 ID = 1
-   `06`: 总长度 = 6 字节（无数据部分）
-   `05`: 命令 = 查询模块信息
-   `55`: 协议尾

## 协议特性

### 自动处理的功能

✅ **粘包处理**: 自动识别多个连续的数据包  
✅ **分包处理**: 自动等待数据包接收完整  
✅ **协议校验**: 自动验证协议头、协议尾和长度字段  
✅ **错误恢复**: 解析失败时自动查找下一个有效包

### 与换行符协议的对比

| 特性     | 二进制协议           | 换行符协议     |
| -------- | -------------------- | -------------- |
| 数据类型 | 支持任意二进制数据   | 仅支持文本数据 |
| 数据长度 | 最大 255 字节        | 无限制         |
| 解析效率 | 高（定长头部）       | 中（需要遍历） |
| 可读性   | 低（二进制）         | 高（文本）     |
| 适用场景 | 嵌入式设备、硬件通信 | 文本协议、调试 |

## 测试

### 使用 Python 发送测试数据

```python
import socket
import struct

def send_strike_packet(host, port, device_id, cmd, data=b''):
    # 构造数据包
    total_length = 6 + len(data)
    packet = struct.pack(
        '>BHBBB',  # 大端序: Header(1), ID(2), Length(1), Cmd(1)
        0xAA,      # Header
        device_id, # ID (2 bytes)
        total_length,  # Length
        cmd,       # Command
    )
    packet += data  # 添加数据部分
    packet += struct.pack('B', 0x55)  # Tail

    # 发送
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.connect((host, port))
    sock.send(packet)

    # 接收响应（如果有）
    response = sock.recv(1024)
    sock.close()

    return response

# 测试：设置1号通道功率为100%
response = send_strike_packet('localhost', 8080, 1, 0x04, b'\x01\x64')
print(f"Response: {response.hex()}")
```

### 使用 Go 发送测试数据

```go
package main

import (
    "fmt"
    "net"
    "uav_defender/internal/pkg/protocol"
)

func main() {
    // 连接服务器
    conn, err := net.Dial("tcp", "localhost:8080")
    if err != nil {
        panic(err)
    }
    defer conn.Close()

    // 构造并发送数据包
    packet := protocol.BuildStrikePacket(
        1,                    // 设备ID
        protocol.CmdSetPower, // 命令
        []byte{0x01, 0x64},  // 数据：通道1，功率100
    )

    _, err = conn.Write(packet)
    if err != nil {
        panic(err)
    }

    // 接收响应
    buffer := make([]byte, 1024)
    n, err := conn.Read(buffer)
    if err != nil {
        panic(err)
    }

    // 解析响应
    response, err := protocol.ParseStrikePacket(buffer[:n])
    if err != nil {
        panic(err)
    }

    fmt.Printf("收到响应: %s\n", response.String())
}
```

```go
}

func (p *YourProtocolParser) Build(data []byte) []byte {
    // 实现你的协议构造逻辑
}

// 使用自定义解析器
serverConfig := utils.TCPServerConfig{
    Parser: &YourProtocolParser{},
    // ... 其他配置
}
```
